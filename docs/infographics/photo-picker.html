Photo Picker

Nine educational infographics, each built around one real-world photograph — the single sanctioned photo on the site. This page collects curated Unsplash search lenses per infographic so you can browse honest, free-to-use candidates and pick the source image. The chosen photo is then duotone-treated toward its tradition's palette (see each brief).

How to use. Each infographic below lists a few lenses — pre-filled Unsplash searches from a different angle. Click a lens (opens Unsplash in a new tab), browse, and note the ones you like. Read each lens's look for / avoid guidance first. When you pick, save the photo's page URL + photographer name so it can be credited in CREDITS.md (Unsplash licence — free, credit appreciated).

Licensing. Every image must be free under the Unsplash licence. Record the photographer + photo URL for each pick; add credit lines to CREDITS.md and drop the treated asset in public/assets/<tradition>/.

Reminder. These photos are a bounded exception to the site's no-photography rule — one treated window per infographic, tinted into the ember room. They are not a licence for stock imagery elsewhere on the site.
